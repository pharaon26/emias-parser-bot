# EMIAS Parser and notifier

Telegram-бот для отслеживания свободных окошек на emias.info (запись к врачам, Москва). Управление полностью через кнопки в чате - никаких конфигов руками. Бот сам сканирует сайт: какие вкладки, цели, направления, специальности и филиалы сейчас доступны, и предлагает их кнопками. Сама запись делается вручную, бот только уведомляет.

## Из фишек
- Бот сам собирает доступные варианты с сайта в реальном времени и отдает их тебе в виде удобных кнопок.
- Скрипт использует плавающие интервалы, накидывая случайные задержки к таймеру, чтобы для серверов ЕМИАС запросы выглядели как действия живого человека, а не зацикленного бота.
- Telegram-интерфейс работает в асинхронном цикле (asyncio), а тяжелый и блокирующий Selenium вынесен в отдельные потоки (run_in_executor). 
- Боту не нужны данные для входа, он использует существующую сессию Google Chrome, тем самым обходя системы защиты при входе.  
- Скрипт не спамит при каждом запуске, он делает слепки доступных окон и присылает алерт только если появился новый врач или у текущего сдвинулась дата приема на более раннюю.  
- Все задачи и состояния хранятся в .json файлах. Cкрипт ничего не забудет, даже если он по какой-то причине отключится, а также отсуствуют тяжелые базы данных).

## Как это устроено

Вход в ЕМИАС остаётся на пользователе - бот использует уже залогиненную сессию из отдельного Chrome-профиля, а не пытается пройти форму входа сам (там CAPTCHA и антифрод-проверки, автоматизировать их не вариант). Логин и пароль от ЕМИАС бот никогда не запрашивает и никуда не пересылает.

Раз в заданный базовый интервал (плюс случайная задержка) бот открывает мастер записи, динамически проходит по сохраненному пути кликов и выбранным филиалам, а затем сравнивает список врачей с тем, что видел в прошлый раз. Если появился новый вариант или у известного врача сдвинулась ближайшая дата - приходит сообщение в Telegram.

## Установка на новом компьютере

### 1. Python

Нужен Python 3.10 или новее.

- macOS: обычно уже стоит, проверить командой `python3 --version` в Terminal.
- Windows: скачать с python.org, при установке отметить галочку "Add Python to PATH".
- Linux: `python3 --version`, если нет - `sudo apt install python3 python3-venv` (Debian/Ubuntu) или аналог для своего дистрибутива.

### 2. Google Chrome

Должен быть установлен обычный Chrome, версии не важна - Selenium сам подхватывает подходящий драйвер.

### 3. Файлы проекта

Скопировать все файлы проекта в одну папку, например `emias-notifier`.

### 4. Виртуальное окружение и зависимости

Из папки проекта:

```bash
python3 -m venv venv
```

Активация:

```bash
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate         # Windows (cmd или PowerShell)
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 5. Настройка .env

Скопировать `.env.example` в `.env` и заполнить:

```bash
cp .env.example .env          # macOS / Linux
copy .env.example .env        # Windows
```

Поля разбираются ниже, по одному.

### 6. Отдельный Chrome-профиль

Бот запускает свою копию Chrome с отдельным профилем - чтобы не мешать основному браузеру и не гонять реальный логин через автоматизацию. Профиль создаётся один раз вручную.

Выбрать пустую папку под профиль (можно в любом месте, не обязательно внутри проекта), например `~/emias-chrome-profile`.

Запустить Chrome с этим профилем и один раз залогиниться на emias.info вручную, как обычно:

macOS:
```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --user-data-dir=~/emias-chrome-profile
```

Windows (cmd):
```bat
"C:\Program Files\Google\Chrome\Application\chrome.exe" --user-data-dir="C:\Users\ИМЯ\emias-chrome-profile"
```

Linux:
```bash
google-chrome --user-data-dir=~/emias-chrome-profile
```

После успешного входа это окно Chrome нужно закрыть. Сессия останется в профиле, бот будет использовать её сам.

В `.env` указать полный путь до этой папки:

```
CHROME_PROFILE_DIR=/Users/имя/emias-chrome-profile
```

На Windows путь пишется как обычно, с обратными слешами или через прямые - оба варианта работают в Python.

Если сессия слетит (бывает время от времени) - бот сам это заметит и пришлёт сообщение с просьбой зайти в тот же профиль и залогиниться заново.

### 7. Telegram-бот

1. Написать **@BotFather** в Telegram, команда `/newbot`, следовать подсказкам. В ответ придёт токен вида `123456:ABC-DEF...`.
2. Вписать токен в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
   ```
3. Написать своему новому боту любое сообщение (например "привет").
4. В браузере открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` подставить токен, слово `bot` перед ним слитно).
5. В ответе найти `"chat":{"id":ЧИСЛО` - это число вписать в `.env`:
   ```
   OWNER_CHAT_ID=ЧИСЛО
   ```

Бот отвечает только этому chat_id, посторонние не смогут им управлять, даже если узнают токен.

### 8. Интервал проверки

В `.env`:
```
CHECK_INTERVAL_MINUTES=10
```

Значение — базовая пауза в минутах, любое целое число. Для защиты от антифрод-систем бот использует механизм джиттера. К базовому интервалу бот каждый раз автоматически добавляется случайная задержка от 1 до 7 минут. Если вы установите значение 20, проверки будут происходить не ровно раз в 20 минут, а случайно в диапазоне от 21 до 27 минут. Слишком маленькое базовое значение ставить не стоит - нет смысла долбить сайт каждую минуту.
### 9. Запуск

```bash
python bot.py
```

Бот откроет собственное окно Chrome при первой проверке или при первом `/add` и будет держать его открытым, пока работает. Закрывать это окно руками не нужно - оно закроется вместе с ботом.

## Команды и кнопки

В чате с ботом снизу есть две постоянные кнопки:

- **Добавить** - то же самое, что команда `/add`. Бот спрашивает, для кого это, затем сам открывает сайт, показывает и дает выбрать цель обращения, специальность и филиалы.
- **Мои записи** - то же самое, что `/list`. Показывает всё, что сейчас отслеживается, с кнопкой удаления под каждой записью.

Команда `/cancel` прерывает диалог добавления в любой момент.

## Для нескольких человек в семье

Если у пользователя в ЕМИАС привязаны полисы близких к одному аккаунту (раздел "Полисы ОМС" на сайте) - хватает одного запущенного бота, один Chrome-профиль покрывает всех, при добавлении просто выбирается нужный человек.

Если привязки нет - на каждого человека, кому нужен отдельный мониторинг, требуется отдельный запуск: своя копия папки проекта, свой Telegram-бот (через BotFather), свой Chrome-профиль со своим логином, запущенный на его собственном компьютере. Бот никогда не пересылает пароли или коды входа - это принципиальное ограничение, а не недоработка.

## Структура проекта

```
bot.py                    - точка входа, все команды и диалоги Telegram
emias_checker.py          - вся логика работы с сайтом через Selenium
targets_store.py          - хранение списка отслеживаемых целей (targets.json)
state_store.py            - хранение состояния проверок (state.json)
requirements.txt
.env.example
```

## Если что-то сломалось

Сайт может со временем немного поменять вёрстку, тогда часть логики в `emias_checker.py` перестанет находить нужные элементы. Признак - в логе появляются строки `WARNING`. Лог стоит смотреть в первую очередь, там обычно видно, на каком шаге и с каким текстом не сошлось.
